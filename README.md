# NovaQI

Storefront for the NovaQI toolkit: trading process, crypto research, and AI developer tools. Browser tools run locally. Checkout and file delivery stay on [Whop](https://whop.com/novaqi).

## Run

Requires Node 22 or newer.

```sh
npm ci
npm run dev
```

Open the printed local URL. `npm run build` produces the production output.

## What is here

- Product catalog with Whop checkout links
- Risk Desk, Review Lab, Strategy Lab, Session Planner, Evidence Desk, and Exposure Lab
- One-page session plan from the Execution Playbook

Suggested prices on the site are launch prices. Live price, tax, and refund terms are on each Whop listing.
